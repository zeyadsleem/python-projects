# My Python Projects

This repository is for me to practice Python with small, fun projects. I’m starting with the Dice Rolling Game and plan to add more projects later, some from LinkedIn Learning and some from my own ideas.

## Current Project: Dice Rolling Game
### What It Does
This game simulates rolling two dice. When you run it:
- It generates two random numbers from 1 to 6.
- It shows you the results.
- It asks if you want to roll again.

It’s a simple project to help me learn the basics.

### My Goals
- Learn to use the `random` module in Python.
- Practice taking user input and using loops.

## How to Run
1. Make sure Python is installed (check `.python-version` for my version).
2. Run the project:
    for example 
    `python projects/dice_rolling_game.py`
